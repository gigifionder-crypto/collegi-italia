# Tomo I — Puglia

## Come leggere questa cartella

**File canonico e attivo:** `opera-integrale-puglia.docx` — corpo integrale del
Tomo I (Parte I–XIII + 33 Appendici Integrative), ~790.000 parole, 1.049
tabelle, 3.891 note. Cifre coerenti con quelle dichiarate nel prompt
operativo (§0: oltre 2.700 pagine, 1.034 tabelle, ~3.891 note).

Questo stesso file contiene fisicamente, in coda al Tomo I, anche una
sezione "Tomo II" (a 4 Blocchi Regionali sommari: Nord/Centro/Sud/Isole) e
una sezione UE-27. Queste due sezioni sono **placeholder superati**: la
versione autorevole del Tomo II Nazionale (regione per regione) e della
sezione UE-27 è quella in `tomo-2-nazionale/opera-unificata-nazionale-e-ue27.docx`
(decisione confermata dall'autore). Le sezioni equivalenti dentro questo
file non vengono cancellate (vincolo §2.2 del prompt operativo) ma vanno
considerate non autorevoli in caso di conflitto.
